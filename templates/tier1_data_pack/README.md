# Tier 1 纯数据模组示范工程 (Data Pack)

本工程是《度日：Daydrift》三体系 Mod 架构中 **Tier 1 纯数据扩展** 的官方标准示范模组。

---

## 体系特性
- **面向群体**：剧本文案作者、世界观策划、美术与音乐同人创作者；
- **编程门槛**：**完全零代码**（无需掌握 Lua 或 GDScript）；
- **核心格式**：JSON 切片 + CSV 多语言翻译表格；
- **安全保障**：物理级零安全风险（包内不含任何可执行指令）；
- **生效机制**：游戏内核的切片数据驱动器在启动时自动合并所有启用的切片，无缝挂载至原版生活物件上。

---

## 包含文件
- `manifest.json`：符合 Schema 规范的清单元数据（声明 `tier: 1`, `type: "data"`）；
- `narrative/slice_afternoon.json`：叙事切片，包含时段触发规则、交互注入与多分支选项；
- `data/i18n/translations.csv`：中、英、日三语对照字典；
- `preview.webp`：模组封面预览图。
